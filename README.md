# 萌芽小院 · Sprout & Guard

一款奶油绘本风的植物塔防网页小游戏。收集阳光、种植植物，守住 5 行 × 9 列的花园。

## 两段花园冒险

- **晴日小院**：3 波进攻，约 3 分钟，适合熟悉种植和防守。
- **落日花园**：4 波进攻，约 4 分钟，路障、铁桶和快步僵尸带来更多挑战。

关卡可以从首页直接选择。清除所有波次的僵尸即可获胜；僵尸越过左侧防线则失败。每行的小推车只能救场一次。

## 怎么玩

1. 点击空中掉落或向日葵生产的阳光，每个增加 25 点阳光。
2. 选择植物卡，再点击空草坪种植。种植消耗阳光，卡片冷却结束后才能再次使用。
3. 射手会自动攻击同一行的僵尸。用坚果争取时间，用寒冰射手减速，必要时使用樱桃炸弹。
4. 选择铲子，再点击植物即可移除；铲除不返还阳光。

| 植物 | 阳光花费 | 作用 |
| --- | ---: | --- |
| 向日葵 | 50 | 定期生产阳光 |
| 豌豆射手 | 100 | 持续攻击同一行 |
| 坚果 | 50 | 承受僵尸啃咬，保护后方植物 |
| 寒冰射手 | 175 | 攻击并减缓僵尸速度 |
| 樱桃炸弹 | 150 | 种下约 1 秒后爆炸，覆盖周围 3 × 3 格 |

开局可以先种两株向日葵，再给有僵尸出现的行补上射手。随后逐步增加向日葵，并补齐五行防线。

## 横屏与操作

- **手机或平板**：横屏后点按植物、草坪和阳光即可游玩。竖屏时游戏暂停，并显示旋转提示。
- **电脑**：用鼠标选择和种植，也可按 `1`–`5` 选择对应植物，按 `6` 选择铲子。
- **暂停**：点击右上角暂停按钮，或按空格；在暂停菜单中点击“继续守护”恢复。
- **取消选择**：按 `Esc`，或再次点击已选择的卡片。
- **声音与全屏**：顶部按钮可开关音效、尝试进入全屏。全屏支持取决于浏览器。

通关记录和声音设置保存在当前浏览器中。暂停菜单可以重新开始或返回首页。

## 本地运行

游戏没有第三方运行依赖、外部素材请求或后端服务。文件齐全时可在断网环境中，通过本地 HTTP 服务器游玩。

由于使用了浏览器 ES Modules，不能直接双击 `index.html`，也不能通过本地文件地址启动。请在本目录启动任意静态 HTTP 服务器。例如，电脑已安装 Python 时：

```sh
python -m http.server 8000
```

随后在浏览器中访问本机的 8000 端口。本地游玩期间需要保持这个服务器运行。

## 发布到 GitHub Pages

1. 把本目录中的文件上传到 GitHub 仓库根目录，确保 `index.html` 直接位于根目录。
2. 在仓库的 **Settings → Pages** 中，将来源设为 **Deploy from a branch**。
3. 选择 **main** 分支和 **/ (root)** 目录，保存并等待 GitHub Pages 完成发布。
4. 使用 Pages 页面显示的站点链接打开游戏和分享给朋友。

这是无需构建的纯静态站点，不需要安装 npm 包、配置数据库或运行后端。发布后由 GitHub 提供网页托管，个人电脑关机不会影响已发布站点的访问。

## 文件说明

- `index.html`：页面结构与界面文字。
- `style.css`：绘本风界面与横屏适配。
- `main.js`：界面交互、动画和声音。
- `engine.js`：植物、僵尸、波次与胜负规则。
- `art.js`：Canvas 角色和场景绘制。
- `icon.svg`、`manifest.webmanifest`：站点图标与网页应用信息。
